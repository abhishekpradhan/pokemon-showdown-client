# Security Policy

This fork is a PS-compatible client and inherits the security sensitivity of the
original Pokémon Showdown client, especially login, session, team storage, chat,
and battle command handling.

## Reporting

Please report security issues privately to the repository owner before opening a
public issue. Include reproduction steps, affected routes, browser details, and
whether the issue affects production, preview deployments, or local development.

## Supported Branch

Security fixes target `main`. Upstream Pokémon Showdown security, protocol, data,
replay, and battle compatibility fixes should be reviewed selectively and ported
when relevant.

## Source Availability

This project remains licensed under AGPLv3. Public deployments must provide users
with access to the corresponding source code for the deployed version.
