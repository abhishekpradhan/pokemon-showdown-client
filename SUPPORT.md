# Support and maintenance

Search [existing issues](https://github.com/abhishekpradhan/pokemon-showdown-client/issues) before reporting a bug. Use the bug or protocol form with the build revision, browser, server, reproduction, expected behavior and a share-safe diagnostic export. Review the export before posting. The feature form asks what workflow is missing and how the official client behaves.

For setup problems, include the failing command and sanitized error, never an environment file. [Self-hosting](docs/self-hosting.md) and [offline recovery](docs/offline.md) cover common deployment and browser-storage problems. Game mechanics, server moderation and official-account issues belong to the relevant Pokémon Showdown community/server support.

The maintainer is [@abhishekpradhan](https://github.com/abhishekpradhan), as recorded in [CODEOWNERS](CODEOWNERS). Maintainers aim to triage new actionable issues weekly, but this is a volunteer project. Use `bug`, `compatibility`, `enhancement`, `documentation`, `good first issue` and `help wanted` to distinguish work; an assigned issue should link to its acceptance criteria. Before implementing a large change, agree its scope in the issue.

Security details belong in the [private reporting process](SECURITY.md). For a confidential community/conduct concern, request a private contact with no details through an issue titled **Private maintainer contact requested**, or use an already-established private channel with the maintainer. Do not post personal information while waiting. GitHub's reporting tools are a separate escalation for abuse on GitHub.

There is currently one listed maintainer. Additional domain maintainers should be added to CODEOWNERS only with their consent. If maintenance changes hands, document the successor, release/signing access, deployment owner, reporting channel and handling of existing confidential reports before transferring responsibility. Community members can maintain an attributed fork under the project license if the project becomes inactive.
